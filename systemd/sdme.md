## general info

Upstream: https://github.com/fiorix/sdme

Written in Rust and with the help of AI.

https://sdme.io/#documentation

#### installation

```
curl -fsSL https://sdme.io/install.sh | sudo sh
```

## usage

#### jump into new container

```
sudo sdme new
```

Exit with CTRL + d.

#### list containers

```
sudo sdme ps
```

#### remove container

```
sudo sdme rm <container_name>
```
